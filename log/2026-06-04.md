# 2026-06-04 开发日志（第2天 - 完成专业与考生管理模块）

## 今日开发任务
完成“专业字典”和“考生档案”两大核心业务模块的后端开发，包括数据实体映射、数据访问层、业务逻辑层以及控制层接口，确保系统具备基础的数据管理能力，并修复项目启动过程中遇到的各种问题。

## 今日完成内容

### 1. 实体层（Entity）开发
- 创建了 `Major.java` 实体类，映射数据库 `major` 表，包含 `majorCode`（主键）、`majorName`、`planInside`、`planOutside` 字段，并使用 `@TableId` 注解标记主键。
- 创建了 `Student.java` 实体类，映射数据库 `student` 表，包含 `examId`（主键）、`name`、`gender`、`age`、`political`、`isFresh`、`education`、`source`、`majorCode`（外键）、`type` 字段。
- 使用 Lombok 的 `@Data` 注解简化了实体类的 Getter/Setter 代码，并添加了 `@TableName` 明确指定数据库表名。

### 2. 数据访问层（Mapper）开发
- 创建了 `MajorMapper.java` 和 `StudentMapper.java` 接口，继承自 MyBatis-Plus 的 `BaseMapper`，实现了对这两个表的基础增删改查能力的自动注入。

### 3. 业务逻辑层（Service）开发
- **Service 接口：** 创建了 `MajorService` 和 `StudentService` 接口，继承自 MyBatis-Plus 的 `IService`。
- **Service 实现类：** 创建了 `MajorServiceImpl` 和 `StudentServiceImpl` 实现类。
    - 使用 `@Service` 注解将类注册为 Spring Bean，解决了之前启动时的 Bean 找不到问题。
    - 在 `MajorServiceImpl` 中，实现了 **带外键检查的删除逻辑**：在删除专业前，会先查询 `student` 表是否还有该专业的考生。如果存在考生，则抛出异常，并利用 `@Transactional` 注解保证整个删除操作的事务性（加分项）。
    - 在 `StudentServiceImpl` 中，完成了基础的 `IService` 功能实现。

### 4. 控制层（Controller）开发
- 创建了 `MajorController.java` 和 `StudentController.java` 控制器类，提供了 RESTful API 接口。
- **`MajorController`**：
    - `GET /major/list`：获取所有专业列表。
    - `POST /major/add`：添加新专业。
    - `DELETE /major/delete/{majorCode}`：删除指定专业（带外键检查）。
- **`StudentController`**：
    - `POST /student/add`：添加新考生。
    - `GET /student/list`：获取所有考生列表。
    - `DELETE /student/delete/{examId}`：删除指定考生。
- 所有接口均统一返回 `Result` 对象，包含 `code`、`msg` 和 `data`。

## 遇到的问题及解决方法

### 1. 编译报错：`java: 找不到符号; 符号: 方法 setCode(int)`
- **问题描述**：`Result.java` 类使用了 Lombok 的 `@Data`，但 IDEA 编译时找不到自动生成的 `setCode`、`setMsg` 等方法。
- **解决方法**：
    1. 检查 `pom.xml` 是否正确引入了 `lombok` 依赖。
    2. **操作步骤**：在 IDEA 中打开 `File` -> `Settings` -> `Build, Execution, Deployment` -> `Compiler` -> `Annotation Processors`，并勾选 **“Enable annotation processing”** 复选框。
    3. 最后执行 `Build` -> `Rebuild Project` 强制重新编译，问题解决。

### 2. Spring 启动报错：`No qualifying bean of type ...`
- **问题描述**：Spring Boot 启动时失败，报错信息显示 `MajorController` 需要 `MajorService` 的 Bean，但找不到；紧接着 `StudentController` 也需要 `StudentService` 的 Bean。
- **解决方法**：
    - 确认 `MajorServiceImpl.java` 和 `StudentServiceImpl.java` 文件已创建。
    - 确保这两个实现类都加上了 **`@Service`** 注解。
    - 检查它们是否被正确地放置在 `com.admission.service.impl` 包下，与 Service 接口在同一个包结构中。
    - 保存文件后，重新运行 `AdmissionSystemApplication.java`，启动成功。

### 3. IDEA 中 `AdmissionSystemApplication.java` 的绿色三角按钮是灰色的
- **问题描述**：项目无法以 Spring Boot 项目的形式运行。
- **解决方法**：
    1. 原因是 IDEA 没有将项目识别为 Maven 项目。
    2. 在右侧 Maven 面板中，点击 `+` 号，手动添加项目根目录下的 `pom.xml` 文件。
    3. IDEA 刷新并加载依赖后，绿色三角按钮重新亮起。
