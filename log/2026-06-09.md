## 遇到的问题及解决方法

### 1. JWT 拦截器导致所有 API 返回 401
- **原因**：WebConfig 注册了 AuthInterceptor，前端未适配 JWT Token 传递。
- **解决**：注释 `addInterceptors` 注册，保留 JwtUtils 和 Token 生成能力但不强制校验。

### 2. BCryptPasswordEncoder 对明文密码抛异常
- **原因**：`matches()` 要求输入是合法 BCrypt 格式（$2a$ 开头），明文 "123456" 导致 IllegalArgumentException。
- **解决**：先判断密码前缀，BCrypt 格式走 matches，明文走 equals 并自动升级加密。

### 3. 分页 Page 对象前端未适配
- **原因**：后端改为返回 Page 对象后，前端 `res.data` 获取到的是 Page 而非数组。
- **解决**：统一改为 `res.data.records || res.data` 取表格数据。
